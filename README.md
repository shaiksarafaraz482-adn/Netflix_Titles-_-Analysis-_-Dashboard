# Netflix Titles Analysis Dashboard

## 📊 Project Overview

This project is a Netflix data analysis dashboard created using Microsoft Power BI.

The dashboard analyzes Netflix movies and TV shows to identify trends based on content type, release year, ratings, genres, countries, and other attributes.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- CSV
- Data Cleaning
- Data Visualization

## 📁 Files in This Repository

- `Netflix_Titles_Analysis_Dashboard.pbix` – Power BI dashboard
- `netflix_titles.csv` – Netflix dataset
- `README.md` – Project documentation

## 🔍 Key Analysis

- Movies vs TV Shows
- Netflix content by release year
- Content by country
- Ratings distribution
- Popular genres
- Movie and TV show duration
- Netflix content trends

## 📈 Dashboard

The interactive dashboard was created in Power BI to provide visual insights from the Netflix dataset.

## 🎯 Project Objective

The objective of this project is to analyze Netflix content and create an interactive dashboard that helps users understand content distribution and trends.
